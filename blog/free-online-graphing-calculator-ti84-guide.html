How to Plot Your First Equation (Step-by-Step)

Getting started with the free online graphing calculator ti-84 takes less than 2 minutes—here’s how to plot a quadratic equation (y = x² - 4) and analyze its roots:

1. Launch the free online graphing calculator ti-84 (no login required)
2. Press MODE → Ensure "FUNCTION" is selected (default mode for y = f(x) equations)
3. Press Y= → Enter the equation: X² - 4 (use X,T,θ,n key for X, x² key for squaring)
4. Press GRAPH → The parabola will appear on the screen
5. To find roots (x-intercepts): Press 2nd+TRACE (CALC) → Select 2:Zero →
- Move cursor left of the first root, press ENTER → Move right of the root, press ENTER → Press ENTER again
6. Repeat step 5 for the second root—you’ll see x = -2 and x = 2 (the solutions to x² - 4 = 0)

Common Graphing Mistake: Equation Syntax Errors

If your graph doesn’t appear, check for syntax errors: use "*" for multiplication (e.g., 2*x instead of 2x), use parentheses for nested functions (e.g., sin(2x) instead of sin2x), and ensure you’re in the correct mode (e.g., FUNCTION mode for y = f(x) equations).
