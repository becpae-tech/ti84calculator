Parametric equations are a powerful tool for describing complex curves that can’t be easily represented with a single function (y = f(x)). Instead of defining y directly in terms of x, parametric equations use a third variable (called a "parameter," usually t) to define both x and y as separate functions: x = x(t) and y = y(t). This makes them ideal for graphing circles, ellipses, spirals, projectiles, and other dynamic paths—common topics in precalculus, calculus, and physics.

The TI-84 Plus CE calculator simplifies parametric graphing with built-in parametric mode and intuitive controls. In this guide, we’ll walk you through every step: switching to parametric mode, entering equations, configuring window settings, plotting curves, and analyzing results. All steps work on both physical TI-84 Plus CE calculators and our free online emulator—so you can practice anywhere, anytime.

Example: Spiral parametric graph on TI-84 Plus CE

What Are Parametric Equations?

Before diving into the TI-84 steps, let’s recap the basics: parametric equations define x and y as functions of a single parameter (typically t, representing time or another independent variable). For example:

  • Circle: x(t) = r·cos(t), y(t) = r·sin(t) (r = radius, t ranges from 0 to 2π)
  • Spiral: x(t) = t·cos(t), y(t) = t·sin(t) (t ranges from 0 to 6π)
  • Projectile Motion: x(t) = v₀·cos(θ)·t, y(t) = v₀·sin(θ)·t - 0.5·g·t² (v₀ = initial velocity, θ = angle, g = gravity)

The key advantage of parametric equations is that they can represent curves that fail the vertical line test (e.g., circles) or change direction (e.g., projectile paths). The TI-84’s parametric mode lets you visualize these curves with just a few button presses.

Prerequisites to Get Started

You’ll need just two things to follow along—no advanced math knowledge required:

  1. A TI-84 Plus CE calculator (physical) or our free online TI-84 Plus CE emulator (we recommend the emulator for easy practice).
  2. A set of parametric equations (we’ll use examples like circles and spirals if you don’t have your own).
  3. Basic familiarity with the TI-84’s core buttons (MODE, Y=, WINDOW, GRAPH) – our TI-84 Guide page has a refresher if you need it.

Step 1: Switch the TI-84 to Parametric Mode

The first step is to tell the calculator you’re working with parametric equations (not standard functions). Here’s how:

1. Press the MODE button (top row of keys, left of 2nd)
2. Scroll down using the arrow keys to the "FUNCTION" line (labeled "FUNC")
3. Use the right arrow key to highlight "PARAMETRIC" (labeled "PAR")
4. Press ENTER to select parametric mode
5. Press 2nd + MODE (QUIT) to exit the MODE menu and return to the home screen

Pro Tip: Verify Mode Selection

After switching to parametric mode, check the top of the Y= menu—you’ll see "X₁T" and "Y₁T" instead of "Y₁" (standard function mode). This confirms you’re ready to enter parametric equations.

Step 2: Enter Your Parametric Equations (x(t) and y(t))

Now you’ll input the x and y components of your parametric equations into the TI-84’s Y= menu. Let’s use a spiral as our example: x(t) = t·cos(t), y(t) = t·sin(t).

  1. Press the Y= button (top left corner of the calculator).
  2. You’ll see fields labeled X₁T, Y₁T, X₂T, Y₂T, etc. (the "T" stands for the parameter).
  3. Navigate to X₁T using the arrow keys.
  4. Enter the x-component: T*cos(T)
    • Press X,T,θ,n (button below MODE) to type "T" (the parameter).
    • Press × (multiplication) to add the "*" symbol.
    • Press 2nd + cos (cosine function) and type "T" again.
  5. Navigate to Y₁T and enter the y-component: T*sin(T)
    • Repeat the steps above, using 2nd + sin for the sine function.
  6. To enter additional parametric equations (e.g., a circle alongside the spiral), use X₂T/Y₂T, X₃T/Y₃T, etc.

Common Syntax Error: Missing Multiplication Symbols

The TI-84 won’t recognize "Tcos(T)"—you must include the multiplication symbol ("T*cos(T)"). Always add "*" between variables and functions.

Step 3: Configure Window Settings for the Parameter

Window settings determine the range of the parameter (t) and the x/y axes—critical for seeing the full curve. For our spiral example (x(t) = t·cos(t), y(t) = t·sin(t)), we’ll use these settings:

  1. Press the WINDOW button (top row, between Y= and ZOOM).
  2. Set the parameter range (Tmin, Tmax, Tstep):
    • Tmin: Starting value of t (e.g., 0 for the spiral).
    • Tmax: Ending value of t (e.g., 6π for a full spiral—press 2nd + π to type π).
    • Tstep: Increment for t (smaller = smoother curve, e.g., 0.1). Too small = slow graphing; too large = jagged curve.
  3. Set the x-axis range (Xmin, Xmax, Xscl):
    • Xmin/Xmax: Minimum/maximum x-values to display (e.g., -20 to 20 for the spiral).
    • Xscl: X-axis scale (e.g., 5 = tick marks every 5 units).
  4. Set the y-axis range (Ymin, Ymax, Yscl):
    • Match Xmin/Xmax for circular/elliptical curves (e.g., -20 to 20 for the spiral) to avoid distortion.
    • Yscl: Y-axis scale (e.g., 5 = tick marks every 5 units).
  5. Press GRAPH to plot the curve!

Step 4: Graph and Analyze the Parametric Curve

Once you’ve entered equations and set the window, press GRAPH—the TI-84 will plot the parametric curve. For our spiral example, you’ll see a curve that expands outward as t increases. Here’s how to analyze the graph:

  1. Trace the Curve:
    • Press TRACE to move along the curve. The calculator will display the current t, x, and y values at the bottom of the screen.
    • Use the left/right arrow keys to move backward/forward through the parameter t.
    • Example: For t=3π, the spiral’s x and y values will be x=3π·cos(3π) ≈ -9.42, y=3π·sin(3π) = 0.
  2. Zoom In/Out:
    • Press ZOOM to access zoom options:
    • Zoom In (2): Magnify a specific area (select a point with arrow keys, press ENTER).
    • Zoom Out (3): Shrink the view to see more of the curve.
    • Zoom Square (5): Adjust x/y scales to make circles look circular (avoids distortion).
    • Zoom Fit (9): Auto-adjust window to fit the entire curve (great if your initial settings cut off the curve).
  3. Calculate Key Points:
    • Press 2nd + TRACE (CALC) to access calculation tools:
    • Value (1): Enter a specific t value to find the corresponding x and y.
    • Intersect (5): Find where two parametric curves intersect (enter a second set of equations in X₂T/Y₂T first).
    • Derivatives (6: dy/dx, 7: dx/dt): Calculate derivatives at a point (calculus feature).

Step 5: Troubleshoot Common Parametric Graphing Issues

Even experienced users run into problems—here’s how to fix the most common parametric graphing errors on the TI-84:

  1. Curve Doesn’t Appear (Blank Screen):
    • Cause 1: Wrong mode (still in FUNCTION mode instead of PARAMETRIC). Fix: Switch to parametric mode (Step 1).
    • Cause 2: Window settings are too narrow (curve is outside x/y range). Fix: Use Zoom Fit (ZOOM → 9) or expand Xmin/Xmax/Ymin/Ymax.
    • Cause 3: Tstep is too large (curve is too jagged to see). Fix: Set Tstep to 0.1 or smaller.
  2. Distorted Curve (e.g., Circle Looks Like Ellipse):
    • Cause: X and Y scales are mismatched. Fix: Use Zoom Square (ZOOM → 5) or set Xmin/Xmax and Ymin/Ymax to the same range (e.g., -10 to 10).
  3. Syntax Error When Entering Equations:
    • Cause: Missing multiplication symbol (e.g., "Tcos(T)" instead of "T*cos(T)") or invalid characters.
    • Fix: Add "*" between variables and functions; use only TI-84’s built-in keys (X,T,θ,n for T).
  4. Slow Graphing:
    • Cause: Tstep is too small (calculator plots too many points) or Tmax is too large.
    • Fix: Increase Tstep to 0.2 (still smooth) or reduce Tmax (e.g., use 4π instead of 6π for a smaller spiral).

Advanced Parametric Graphing Tips

Once you master the basics, these tips will help you create more complex parametric graphs and get more from your TI-84:

  • Graph Multiple Parametric Curves:

    Enter additional equations in X₂T/Y₂T, X₃T/Y₃T, etc. (e.g., a circle and a spiral on the same graph). Each curve will appear in a different color for easy differentiation.

  • Restrict the Parameter Range:

    Plot only a portion of a curve by adjusting Tmin/Tmax (e.g., Tmin=π/2, Tmax=3π/2 for the left half of a circle).

  • Use Piecewise Parametric Equations:

    Combine multiple curves with the "if" command (2nd + MATH → TEST → 1:if). Example: Plot a circle for t=0-2π and a line for t=2π-4π.

  • Save Window Settings:

    Store custom window settings for common curves (e.g., circles) using ZOOM → STORE → select a number (1-9). Recall later with ZOOM → RECALL.
