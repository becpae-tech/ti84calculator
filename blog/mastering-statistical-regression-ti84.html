Statistical regression is one of the most powerful tools in data analysis—whether you’re analyzing experimental results, predicting trends, or solving real-world math problems. The TI-84 Plus CE calculator simplifies regression analysis with built-in functions for linear, quadratic, exponential, and more models, making it a go-to tool for students, teachers, and researchers.

In this guide, we’ll break down everything you need to master regression on the TI-84 Plus CE: from inputting data to interpreting key metrics like correlation coefficient (r) and coefficient of determination (r²), plotting regression curves, and validating models with residual graphs. We’ll use practical examples (like student study time vs. test scores) so you can apply what you learn immediately—on a physical TI-84 or our free online emulator.

What Is Statistical Regression?

Regression analysis is a statistical method that finds the relationship between two or more variables. For most TI-84 users, this means finding a mathematical equation (the "regression model") that best fits a set of (x, y) data points. The goal is to:

  • Describe the relationship between variables (e.g., "As study time increases, test scores tend to increase").
  • Predict unknown y-values from given x-values (e.g., "A student who studies 5 hours will score 85 on the test").
  • Measure how well the model fits the data (using metrics like r²).

The TI-84 Plus CE supports 7+ regression models—we’ll focus on the three most commonly used:

<Regression Type <Equation Form <Best For Linear (LinReg) y = ax + b Straight-line relationships (e.g., study time vs. test score) Quadratic (QuadReg) y = ax² + bx + c Curved relationships with one peak/valley (e.g., height vs. time for a projectile) Exponential (ExpReg) y = abˣ Growth/decay relationships (e.g., population growth, radioactive decay)

How to Choose the Right Model

Always start by plotting your data (STAT PLOT) to visualize the pattern. If the points form a straight line, use linear regression. If they curve upward/downward with a single bend, use quadratic. If they grow or decay rapidly, use exponential.

Step 1: Input Data into TI-84 Lists

Regression analysis starts with entering your data into the TI-84’s "lists" (spreadsheet-like columns for storing data). Here’s how to do it:

  1. Press the STAT button (located in the top row of the TI-84 keypad).
  2. Select 1:Edit... and press ENTER—you’ll see columns labeled L1, L2, L3, etc.
  3. Clear existing data (if needed):
    • Use the arrow keys to highlight the list name (e.g., L1) at the top of the column.
    • Press CLEAR (not DEL!) and then ENTER—this clears the entire list without deleting it.
  4. Enter x-values (study time) into L1:
    • Type the first x-value (1) and press ENTER.
    • Continue entering all x-values (2, 3, 4, 5, 6), pressing ENTER after each.
  5. Use the arrow keys to move to L2 and enter the corresponding y-values (65, 70, 78, 85, 92, 95), pressing ENTER after each.
  6. Press 2nd + MODE (QUIT) to exit the list editor and return to the home screen.

Pro Tip for Large Data Sets

If you have dozens of data points, use the TI-84’s "paste" function or import data from a computer (physical calculator only). For most student projects, manual entry is fast and simple.

Step 2: Plot Data to Visualize the Relationship

Before choosing a regression model, always plot your data to see the pattern. This helps you avoid picking the wrong model (e.g., using linear regression for curved data):

  1. Press 2nd + Y= (STAT PLOT) to open the plot menu.
  2. Select 1:Plot1... and press ENTER.
  3. Turn Plot1 ON (use the arrow keys to highlight "ON" and press ENTER).
  4. Select the scatter plot icon (first option under "Type"—looks like dots).
  5. Verify the data source:
    • Xlist: L1 (x-values)
    • Ylist: L2 (y-values)
    • Mark: Choose any dot style (we recommend the first option for clarity).
  6. Press GRAPH—you’ll see the scatter plot of study time vs. test score. For our sample data, the points form a straight line (perfect for linear regression!).
  7. Use the ZOOM button if needed: Select 9:ZoomStat to auto-adjust the window to fit all data points.

Step 3: Perform Linear Regression (LinReg)

Now we’ll find the linear equation (y = ax + b) that best fits the data. Linear regression is the most common model—we’ll cover quadratic and exponential later:

  1. Press STAT and use the right arrow key to highlight the CALC menu.
  2. Select 4:LinReg(ax+b) and press ENTER.
  3. The calculator will prompt you to confirm the data lists (Xlist: L1, Ylist: L2)—press ENTER twice to run the regression.
  4. You’ll see the regression results on the home screen (we’ll interpret these next!).
LinReg(ax+b) y = ax + b a = 7.142857143 b = 58.28571429 r = .9899494937 r² = .9799999999

Step 4: Interpret Regression Results

The TI-84’s regression output includes key metrics—here’s what each one means for our sample data (linear regression):

<
Metric <Value (Sample Data) <Interpretation
a 7.14 Slope of the regression line: For every 1-hour increase in study time, test score increases by ~7.14 points.
b 58.29 Y-intercept: A student who studies 0 hours is predicted to score ~58.29 points.
r (Correlation Coefficient) 0.99 Measures the strength of the linear relationship: -1 = perfect negative correlation, 1 = perfect positive correlation, 0 = no correlation. Our r = 0.99 means a strong positive linear relationship.
r² (Coefficient of Determination) 0.98 Percentage of variation in y explained by x: 98% of the variation in test scores is explained by study time—this means the model fits the data extremely well!

Where’s r and r²? (Common Issue!)

If r and r² don’t appear in your output, you need to turn on "DiagnosticOn":

  1. Press 2nd + 0 (CATALOG) to open the command catalog.
  2. Scroll down to "DiagnosticOn" (use the arrow keys or type "D" with ALPHA).
  3. Press ENTER twice—you’ll see "Done" on the home screen.
  4. Rerun the regression (Step 3) to see r and r².

Step 5: Plot the Regression Line with Data Points

Visualize how well the regression line fits your data by overlaying it on the scatter plot:

  1. Press Y= to open the function menu.
  2. Clear any existing functions (press CLEAR on each line).
  3. Press STAT and use the right arrow key to highlight the CALC menu.
  4. Select 4:LinReg(ax+b) again—but this time, after selecting it, press VARS.
  5. Use the right arrow key to highlight Y-VARS, select 1:Function, then 1:Y1, and press ENTER.
  6. Press ENTER twice to run the regression and store the equation in Y1.
  7. Press GRAPH—you’ll see the scatter plot (data points) and the regression line (straight line) overlaid. For our sample data, the line will almost touch all points (thanks to r² = 0.98!).

Step 6: Make Predictions with the Regression Model

One of the most useful features of regression is predicting unknown y-values. Let’s predict the test score for a student who studies 4.5 hours (our data only goes up to 6 hours):

Method 1: Use the Regression Equation

  1. From our results, the equation is y = 7.14x + 58.29.
  2. Plug x = 4.5 into the equation: y = 7.14(4.5) + 58.29 ≈ 32.13 + 58.29 = 90.42.
  3. Predicted test score: ~90 points.

Method 2: Use the TI-84’s CALC Menu (Faster!)

  1. Press 2nd + TRACE (CALC) to open the calculation menu.
  2. Select 1:value and press ENTER.
  3. When prompted "X=", type 4.5 and press ENTER.
  4. The calculator will display "Y=90.428571"—the predicted test score (matches our manual calculation!).

Important Prediction Rule

Only predict x-values within the range of your original data (this is called "interpolation"). Our x-values are 1-6 hours—predicting for 4.5 hours is safe, but predicting for 10 hours (extrapolation) is risky (the relationship might not hold beyond your data).

Step 7: Quadratic & Exponential Regression (Quick Guide)

For curved data, use quadratic or exponential regression— the process is almost identical to linear regression:

Quadratic Regression (QuadReg)

  1. Follow Steps 1-2 (input data + plot scatter plot) to confirm the data is curved (one peak/valley).
  2. Press STAT → CALC → 5:QuadReg and press ENTER twice.
  3. Results include a (x² coefficient), b (x coefficient), c (constant), and r² (model fit).
  4. Store the equation in Y1 (as in Step 5) and graph to see the parabola.

Exponential Regression (ExpReg)

  1. Use for growth/decay data (e.g., population = 1000, 2000, 4000, 8000 over time).
  2. Press STAT → CALC → 0:ExpReg and press ENTER twice.
  3. Results include a (initial value) and b (growth/decay factor), plus r².
  4. Store in Y1 and graph to see the exponential curve.
<Regression Type <TI-84 CALC Option <Key Metric for Fit Linear 4:LinReg(ax+b) r (closer to ±1 = better fit) Quadratic 5:QuadReg r² (closer to 1 = better fit) Exponential 0:ExpReg r² (closer to 1 = better fit)

Step 8: Validate Model Fit with Residual Graphs

Residuals are the differences between your actual y-values and the predicted y-values (residual = actual y - predicted y). A good model will have residuals randomly scattered around 0—no pattern means the model fits well:

  1. Run your regression (e.g., LinReg) and store the equation in Y1 (Step 5).
  2. Press STAT → EDIT to open the list editor.
  3. Use the arrow keys to highlight the L3 column name and press ENTER.
  4. Type L2 - Y1(L2) (actual y - predicted y) and press ENTER—L3 will populate with residuals.
  5. Press 2nd + Y= (STAT PLOT) and select 2:Plot2....
  6. Turn Plot2 ON, select the scatter plot icon, set Xlist = L1, Ylist = L3, and press GRAPH.

How to Interpret Residual Graphs:

  • Random scatter (no pattern): Model fits well (our sample data will look like this!).
  • Curved pattern: Wrong model (e.g., linear regression for quadratic data—switch to QuadReg).
  • Residuals increasing/decreasing: Model under/overestimates values (check data entry or try a different model).

Common Regression Errors & How to Fix Them

Even experienced users run into issues—here’s how to fix the most common regression problems on the TI-84:

  1. "ERR:INVALID DIM" (Invalid Dimension):
    • Cause: L1 and L2 have different numbers of data points (e.g., 6 x-values but 5 y-values).
    • Fix: Go back to STAT → EDIT and ensure both lists have the same number of entries.
  2. No Regression Results (Blank Screen):
    • Cause: Lists are empty or have only one data point (regression needs at least 2 points).
    • Fix: Add more paired (x, y) values to L1 and L2.
  3. r and r² Missing from Output:
    • Cause: Diagnostic mode is off (common default setting).
    • Fix: Turn on DiagnosticOn (Step 4 note box) and rerun the regression.
  4. Regression Line Doesn’t Appear on Graph:
    • Cause: The line is outside the graph window or the equation wasn’t stored in Y1.
    • Fix: Press ZOOM → 9:ZoomStat to auto-adjust the window, or re-store the equation in Y1 (Step 5).
  5. Low r² (Poor Model Fit):
    • Cause: Wrong model type or no relationship between x and y.
    • Fix: Plot the data again and try a different regression model (e.g., exponential instead of linear).

Advanced Regression Tips for TI-84

Once you master the basics, these tips will help you get more from your regression analysis:

  • Compare Multiple Models: Run linear, quadratic, and exponential regression on the same data and compare r²—higher r² means a better fit.
  • Save Regression Equations: Store frequently used equations in Y1-Y9 for quick access (Step 5 method works for all models).
  • Use Logistic Regression for S-Curves: For data that plateaus (e.g., growth that levels off), use STAT → CALC → B:Logistic.
  • Print Results (Physical Calculator): Connect your TI-84 to a computer and print regression tables for lab reports or homework.
